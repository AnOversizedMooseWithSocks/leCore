leCore — BM25 + containment in WebGL2, with answer / set / abstain

One fragment pass computes both the BM25 score and the exact containment count, by binary search over each document's sorted-unique terms. No vocabulary table is shipped: a term's id is its FNV-1a hash. The page calibrates its own abstain threshold from 200 scrambled queries, so the threshold describes what actually runs.
